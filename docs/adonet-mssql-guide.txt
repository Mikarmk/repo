ADO.NET + MSSQL guide

1. Что нужно на экзамене
   - SQL Server или SQL Server Express.
   - Visual Studio с .NET desktop development.
   - Строка подключения к серверу.

2. Где менять строку подключения
   - В WPF-проектах используется файл App.config.
   - Ищите секцию connectionStrings.

3. Примеры строк подключения

   Windows Authentication:
   Data Source=localhost\SQLEXPRESS;Initial Catalog=TransportLogisticsDemo;Integrated Security=True;TrustServerCertificate=True

   SQL Login:
   Data Source=localhost;Initial Catalog=TransportLogisticsDemo;User ID=sa;Password=YourStrongPassword;TrustServerCertificate=True

4. Базовый код подключения

   using System.Data.SqlClient;

   var connectionString = ConfigurationManager.ConnectionStrings["AppDb"].ConnectionString;

   using (var connection = new SqlConnection(connectionString))
   {
       connection.Open();
   }

5. Как выполнять SELECT

   using (var connection = new SqlConnection(connectionString))
   using (var command = new SqlCommand("SELECT Login, FullName FROM dbo.AppUsers", connection))
   {
       connection.Open();

       using (var reader = command.ExecuteReader())
       {
           while (reader.Read())
           {
               var login = reader.GetString(0);
               var fullName = reader.GetString(1);
           }
       }
   }

6. Как выполнять INSERT/UPDATE через параметры

   using (var connection = new SqlConnection(connectionString))
   using (var command = new SqlCommand(
       "INSERT INTO dbo.AppUsers (Login, PasswordHash, FullName, RoleId) VALUES (@Login, @PasswordHash, @FullName, @RoleId)",
       connection))
   {
       command.Parameters.AddWithValue("@Login", login);
       command.Parameters.AddWithValue("@PasswordHash", passwordHash);
       command.Parameters.AddWithValue("@FullName", fullName);
       command.Parameters.AddWithValue("@RoleId", roleId);

       connection.Open();
       command.ExecuteNonQuery();
   }

7. Что обязательно объяснить на защите
   - Почему используются параметризованные запросы.
   - Где хранится строка подключения.
   - Как открывается SqlConnection.
   - Чем ExecuteReader отличается от ExecuteNonQuery.
   - Как обрабатываются исключения SqlException.

8. Частые проблемы
   - Неверное имя сервера.
   - База еще не создана.
   - В строке подключения нет TrustServerCertificate=True.
   - Неверный логин SQL Server.
   - Приложение смотрит в другую БД, чем выполнялись SQL-скрипты.

9. Минимальная схема запуска
   - Выполнить 01_create_database.sql.
   - Выполнить 02_import_staging.sql.
   - Выполнить 03_normalize_and_seed.sql.
   - Проверить вход тестовой учетной записью.
   - Запустить приложение и проверить загрузку главного списка.

10. Если работа идет через Entity Framework

Это уже не ручной `SqlConnection`, а работа через контекст БД, например:

   DemoTestEntities db = new DemoTestEntities();

Обычно это `Entity Framework Database First`.

Пример загрузки таблицы в DataGrid:

   DemoTestEntities db = new DemoTestEntities();

   public AdminWindow()
   {
       InitializeComponent();
       DataGridUsers.ItemsSource = db.Users.ToList();
   }

Пример авторизации:

   private void LoginBTN_Click(object sender, RoutedEventArgs e)
   {
       string login = LoginBox.Text;
       string password = PasswordBox.Password;

       using (var db = new DemoTestEntities())
       {
           var user = db.Users.FirstOrDefault(x => x.Login == login && x.Password == password);

           if (user == null)
           {
               MessageBox.Show("Пользователь не найден");
               return;
           }

           MessageBox.Show("Добро пожаловать, " + user.Fio);

           if (user.RolID == 1)
           {
               new AdminWindow().Show();
               Close();
               return;
           }

           if (user.RolID == 2)
           {
               new UserWindow().Show();
               Close();
               return;
           }

           MessageBox.Show("Роль пользователя не определена");
       }
   }

Пример сохранения из DataGrid:

   private void SaveBTN_Click(object sender, RoutedEventArgs e)
   {
       UsersGrid.CommitEdit();
       db.SaveChanges();
       MessageBox.Show("Изменения сохранены");
   }

Пример добавления:

   private void AddBTN_Click(object sender, RoutedEventArgs e)
   {
       Users user = new Users
       {
           Login = LoginTB.Text,
           Password = PasswordTB.Text,
           Fio = FioTB.Text,
           RolID = 2
       };

       db.Users.Add(user);
       db.SaveChanges();
       MessageBox.Show("Пользователь добавлен");
   }

Пример удаления:

   private void DeleteBTN_Click(object sender, RoutedEventArgs e)
   {
       Users selectedUser = UsersGrid.SelectedItem as Users;

       if (selectedUser == null)
       {
           MessageBox.Show("Выберите пользователя");
           return;
       }

       db.Users.Remove(selectedUser);
       db.SaveChanges();
       MessageBox.Show("Пользователь удален");
   }

11. Что говорить на защите, если работаешь через Entity Framework

   - `DemoTestEntities` это контекст базы данных.
   - `db.Users` это отображение таблицы `Users`.
   - `ToList()` загружает список строк.
   - `FirstOrDefault()` возвращает первую найденную запись или `null`.
   - `Add()` добавляет запись в контекст.
   - `Remove()` удаляет запись из контекста.
   - `SaveChanges()` сохраняет изменения в базе данных.
