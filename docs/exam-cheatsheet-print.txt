4. ADO.NET МИНИМУМ

using System.Data.SqlClient;
using System.Configuration;

var connectionString = ConfigurationManager.ConnectionStrings["AppDb"].ConnectionString;

using (var connection = new SqlConnection(connectionString))
{
    connection.Open();
}

SELECT:
using (var command = new SqlCommand("SELECT * FROM dbo.AppUsers", connection))
using (var reader = command.ExecuteReader())
{
    while (reader.Read())
    {
    }
}

INSERT / UPDATE:
using (var command = new SqlCommand("INSERT INTO dbo.AppUsers(Login, PasswordHash) VALUES(@Login, @PasswordHash)", connection))
{
    command.Parameters.AddWithValue("@Login", login);
    command.Parameters.AddWithValue("@PasswordHash", password);
    command.ExecuteNonQuery();
}

4.1 ЕСЛИ РАБОТАЕШЬ ЧЕРЕЗ ENTITY FRAMEWORK

Твой стиль работы выглядит так:

using (var db = new DemoTestEntities())
{
    var user = db.Users.FirstOrDefault(x => x.Login == login && x.Password == password);
}

Что это значит:
- это не ADO.NET вручную
- это Entity Framework
- чаще всего Database First
- подключение идет через `.edmx` и строку подключения в `App.config`

Минимальный шаблон авторизации через EF:

using (var db = new DemoTestEntities())
{
    var user = db.Users.FirstOrDefault(x => x.Login == login && x.Password == password);

    if (user == null)
    {
        MessageBox.Show("Пользователь не найден");
        return;
    }

    if (user.RolID == 1)
    {
        MessageBox.Show("Добро пожаловать, " + user.Fio);
        new AdminWindow().Show();
        Close();
        return;
    }

    if (user.RolID == 2)
    {
        MessageBox.Show("Добро пожаловать, " + user.Fio);
        new UserWindow().Show();
        Close();
        return;
    }

    MessageBox.Show("Роль пользователя не определена");
}

Что помнить для EF:
- `DemoTestEntities` = контекст базы
- `db.Users` = таблица Users
- `FirstOrDefault()` = взять первую запись или null
- `Include()` = если нужно подтянуть связанные таблицы
- `SaveChanges()` = сохранить изменения в БД

Пример добавления через EF:

using (var db = new DemoTestEntities())
{
    var user = new Users
    {
        Login = "test",
        Password = "123",
        Fio = "Тестовый пользователь",
        RolID = 2
    };

    db.Users.Add(user);
    db.SaveChanges();
}

Пример редактирования через EF:

using (var db = new DemoTestEntities())
{
    var user = db.Users.FirstOrDefault(x => x.ID == id);
    if (user == null)
    {
        MessageBox.Show("Запись не найдена");
        return;
    }

    user.Fio = FioBox.Text;
    user.Login = LoginBox.Text;
    db.SaveChanges();
}

Пример удаления через EF:

using (var db = new DemoTestEntities())
{
    var user = db.Users.FirstOrDefault(x => x.ID == id);
    if (user == null)
    {
        MessageBox.Show("Запись не найдена");
        return;
    }

    db.Users.Remove(user);
    db.SaveChanges();
}

5. ЧТО ГОВОРИТЬ ПРО ADO.NET

- SqlConnection открывает соединение.
- SqlCommand выполняет запрос.
- SqlDataReader читает строки SELECT.
- ExecuteReader = чтение данных.
- ExecuteNonQuery = INSERT / UPDATE / DELETE.
- Параметры нужны для защиты от SQL Injection.

6. АВТОРИЗАЦИЯ

Обычно логика такая:

SELECT TOP 1 UserId, Login, FullName, RoleId
FROM dbo.AppUsers
WHERE Login = @Login
  AND PasswordHash = @PasswordHash
  AND IsActive = 1

Если запись есть:
- открыть главное окно
- передать currentUser

Если записи нет:
- показать MessageBox "Неверный логин или пароль"

Если работаешь через EF:
- `db.Users.FirstOrDefault(...)`
- дальше проверка `user == null`
- потом переход по `RolID`

13. SQL-ОТЧЕТЫ, КОТОРЫЕ МОЖНО БЫСТРО СДЕЛАТЬ

Количество:
SELECT StatusName, COUNT(*) FROM dbo.Orders GROUP BY StatusName;

Среднее:
SELECT AVG(CAST(TransitDays AS decimal(18,2))) FROM dbo.Orders;

Сумма:
SELECT SUM(Quantity * UnitPrice) FROM dbo.OrderItems;

TOP:
SELECT TOP (10) Name, Price FROM dbo.Products ORDER BY Price DESC;
