Algorithm

1. Менеджер входит в систему и открывает список заявок партнеров.
2. Система показывает сумму заявки как сумму Quantity * UnitPrice.
3. Поиск работает по названию партнера и директору.
4. Форма карточки используется для добавления и редактирования заявки.
5. Дополнительный экран может показывать предложенную продукцию по выбранному партнеру.
