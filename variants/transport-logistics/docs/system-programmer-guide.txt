System programmer guide

- Назначение: Система для управления транспортными заказами, производителями, потребителями и перевозчиками.
- Сервер БД: SQL Server
- Клиент: WPF .NET Framework 4.8
- Подключение: ADO.NET через System.Data.SqlClient
- Базовая диагностика: проверить App.config, строку подключения, наличие таблицы AppUsers и представления v_MainRecords.
