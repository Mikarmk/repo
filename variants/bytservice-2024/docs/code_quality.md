# Качественные характеристики кода

- Полнота обработки ошибочных данных: реализованы проверки обязательных полей, пустого логина и пароля, подтверждение удаления и проверка согласования продления с клиентом.
- Наличие тестов допустимых значений входных данных: подготовлен протокол функционального тестирования в `docs/testing.md`.
- Средства контроля корректности входных данных: используются проверки перед сохранением форм и сообщения об ошибках.
- Средства восстановления при сбоях оборудования: данные хранятся в SQL Server, предусмотрен отдельный скрипт резервного копирования.
- Наличие комментариев: комментарии используются только в документации и SQL, в коде оставлен минимальный уровень для неочевидных мест.
- Проверка корректности передаваемых данных: все запросы к SQL Server параметризованы.
- Наличие описаний основных функций: описание модулей и алгоритмов приведено в `README.md`, `docs/specification.md` и `docs/system_programmer_guide.md`.
