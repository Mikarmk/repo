# Протокол функционального тестирования

Дата подготовки: `2026-05-12`

| № | Функция | Входные данные | Ожидаемый результат | Фактический результат |
|---|---|---|---|---|
| 1 | Авторизация | `kasoo / root` | Успешный вход под менеджером по качеству | Подлежит проверке на Windows |
| 2 | Создание заявки | Валидные поля карточки заявки | Новая запись появляется в списке | Подлежит проверке на Windows |
| 3 | Поиск заявки | Часть модели техники | Список фильтруется по введенной строке | Подлежит проверке на Windows |
| 4 | Добавление комментария | Комментарий мастера | Комментарий сохраняется в таблице `RequestComments` | Подлежит проверке на Windows |
| 5 | Продление срока | Новая дата + согласование клиента | Поле `ExtendedUntil` обновляется | Подлежит проверке на Windows |
| 6 | Расчет статистики | Наличие завершенных заявок | Отображается количество и среднее время ремонта | Подлежит проверке на Windows |
| 7 | Генерация QR-кода | Выбранная заявка | Открывается окно с QR-кодом и ссылкой | Подлежит проверке на Windows |
