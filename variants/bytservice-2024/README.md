# БытСервис Demo

Готовое решение под демонстрационный вариант `В1_КОД 09.02.07-2-2024-ПУ`:

- WPF-приложение для учета заявок на ремонт бытовой техники
- T-SQL-скрипты создания БД, загрузки данных, отчетов, ролей и резервного копирования
- импорт исходных данных из варианта
- эксплуатационные документы в каталоге `docs`

## Структура

- `src/BytService.App` - WPF-клиент на C#
- `scripts` - SQL-скрипты
- `assets/import` - исходные файлы импорта из варианта
- `docs` - спецификация, ERD, тесты и сопроводительные документы

## Быстрый запуск

1. Открыть `scripts/01_create_database.sql` и выполнить на SQL Server.
2. Выполнить `scripts/02_import_data.sql`.
3. При необходимости выполнить `scripts/03_reports.sql`, `scripts/04_security.sql`, `scripts/05_backup.sql`.
4. Открыть решение `PraktikaDemo.sln` в Visual Studio 2022 на Windows.
5. Проверить строку подключения в `src/BytService.App/appsettings.json`.
6. Запустить проект `BytService.App`.

## Что реализовано

- авторизация и разграничение доступа по ролям
- просмотр, поиск, добавление и редактирование заявок
- назначение мастера, продление срока, привлечение дополнительного мастера
- комментарии мастеров к заявкам
- расчет статистики по выполненным заявкам и среднему времени ремонта
- генерация QR-кода на форму обратной связи
- SQL-отчеты и готовый импорт данных
