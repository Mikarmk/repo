# WPF ADO.NET Template

Шаблонный проект для экзамена:

- `.NET Framework 4.8`
- `WPF`
- `System.Data.SqlClient`
- окно авторизации
- блокировка входа после 3 ошибок
- опциональная CAPTCHA
- главное окно
- окно профиля
- окно добавления и редактирования записи
- ADO.NET helper classes

Шаблон можно копировать в `variants/<variant>/src`.
